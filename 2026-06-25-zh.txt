  <h1 style="font-size:30px; line-height:1.35; color:#111; margin:0 0 18px;">2026年6月25日韩国股市收盘：半导体龙头推升KOSPI，但KOSDAQ疲弱显示资金分化</h1>
  <p style="font-size:16px; margin:0 0 14px;">2026年6月25日，韩国股市表面上是一场强劲反弹，但内部结构并不均衡。KOSPI收于9,013.69点，较前一交易日上涨6.41%，盘中最高触及9,017.27点，基本修复了此前急跌带来的部分恐慌情绪。1) 不过，KOSDAQ收于888.74点，下跌2.26%，重新跌回900点下方。2)</p>
  <p style="font-size:16px; margin:0 0 18px;">今天的核心不是“韩国股票全面上涨”，而是“资金集中回到大型半导体股”。三星电子和SK海力士明显走强，带动KOSPI大幅反弹；但中小成长股、部分生物科技和二次电池相关股票的气氛仍然偏弱。3)4)8) SK海力士推进美国ADR上市、美国美光发布强于预期的营收和积极指引，共同强化了市场对AI存储需求的信心。5)6)</p>

  <h2 style="font-size:24px; margin:28px 0 12px; color:#111;">为什么KOSPI反弹这么强？</h2>
  <p>KOSPI从前一交易日的8,471.02点升至9,013.69点，全天低点也维持在8,693.62点，高于前一日收盘位置。1) 这说明买盘并不是只在尾盘做短线反弹，而是在白天交易中持续回到韩国最重要的半导体权重股。</p>
  <p>理解韩国股市时，指数结构非常重要。KOSPI受少数超大型科技股影响很大，尤其是三星电子和SK海力士。当这两家公司同时上涨时，指数会显得非常强，即使市场中很多普通股票并没有同样上涨。今天就是这种典型情况：指数层面释放出“恐慌缓和”的信号，但市场广度并不理想。</p>
  <h2 style="font-size:24px; margin:28px 0 12px; color:#111;">KOSDAQ为什么反而下跌？</h2>
  <p>KOSDAQ全天波动区间为884.05至930.81点，最终收在888.74点，低于前一交易日的909.31点。2) 这反映出成长股资金面仍然脆弱。KOSDAQ中有较多生物科技、二次电池、软件、设备材料等公司，这些股票对风险偏好和流动性变化更敏感。</p>
  <p>韩国本地报道也指出，6月以来个人投资者资金明显流向三星电子和SK海力士，而二次电池、生物科技等此前受到关注的行业相对疲弱。8) 对投资者来说，这意味着今天的上涨不是“全部股票一起恢复”，而是资金在寻找最确定的AI半导体主线。</p>
  <h2 style="font-size:24px; margin:28px 0 12px; color:#111;">主要催化：SK海力士推进美国ADR上市</h2>
  <p>今天最重要的个股催化来自SK海力士。韩联社报道称，SK海力士计划于7月10日推动美国ADR在纳斯达克交易，潜在融资规模可达45万亿韩元以上。5) 相关资金将用于龙仁半导体集群、清州先进封装工厂以及EUV设备等设施投资。5)</p>
  <p>市场之所以积极反应，不只是因为“赴美上市”本身具备话题性，更是因为这被视为公司继续加码AI存储投资的信号。AI服务器建设需要高带宽内存和先进封装能力，而这些环节正是全球供应链中最受关注的瓶颈之一。如果ADR带来更多海外机构资金关注，SK海力士的估值讨论也可能进一步国际化。</p>
  <h2 style="font-size:24px; margin:28px 0 12px; color:#111;">美光业绩给AI存储交易带来安慰</h2>
  <p>美光的业绩消息是另一项重要支撑。Business Insider报道称，美光营收超过华尔街预期，并给出积极指引，这强化了市场对AI相关存储需求的乐观情绪。6) 最近市场担心AI交易估值过高、资金过于拥挤，因此任何能证明需求仍然强劲的业绩信号都会被放大。</p>
  <p>这也是三星电子和SK海力士反应强烈的原因。它们的股价不仅取决于当前利润，还取决于投资者是否相信AI数据中心建设会继续推升存储需求。今天市场给出的答案偏积极，但资金明显更愿意选择与AI存储需求关系最直接的大型公司。</p>
  <h2 style="font-size:24px; margin:28px 0 12px; color:#111;">代表股票：三星电子与SK海力士</h2>
  <p>三星电子收于359,000韩元，上涨5.43%。3) 在前一交易日大幅反弹之后还能继续上涨，说明市场仍愿意配置韩国最大科技股。不过，三星电子近期波动很大，后续需要观察盈利预期能否继续支撑当前股价。</p>
  <p>SK海力士收于2,954,500韩元，大涨14.52%，是今天最受关注的股票。4) ADR上市计划、AI存储需求和大规模设施投资三条叙事同时出现，使资金迅速集中。但投资者也需要看到另一面：一天内涨幅过大后，短期获利回吐随时可能出现。好消息本身很重要，市场已经提前反映多少同样重要。</p>
  <h2 style="font-size:24px; margin:28px 0 12px; color:#111;">投资情绪：从恐慌转向缓和，但集中度更高</h2>
  <p>本周早些时候KOSPI曾出现接近10%的急跌，投资者情绪非常紧张。今天KOSPI重回9,000点上方后，恐慌明显缓和。Business Insider提到，有分析认为近期回调更像长期上涨中的降温，而不是趋势彻底逆转，但市场波动仍可能持续。6)</p>
  <p>韩国散户参与度也处在很高水平。韩联社报道称，截至6月24日，韩国股票交易活跃账户达到1亿877万个，反映今年韩国股市大涨后投资热度持续升温。7) 高参与度有助于成交活跃，但也可能放大拥挤交易的波动。当大量资金同时关注同一批AI和半导体股票时，即使是利好消息也可能带来剧烈震荡。</p>
  <h2 style="font-size:24px; margin:28px 0 12px; color:#111;">下一交易日需要关注什么？</h2>
  <ul style="padding-left:20px; margin:0 0 18px;">
    <li>SK海力士ADR上市相关后续公告和海外机构需求。</li>
    <li>三星电子、SK海力士的强势能否扩散到半导体材料、设备和KOSDAQ股票。</li>
    <li>KOSDAQ能否重新站上900点，改善市场广度。</li>
    <li>美光业绩后美国半导体股在正式交易中的表现。</li>
    <li>大型半导体股急涨后是否出现短线获利回吐。</li>
  </ul>
  <p style="background:#fff8e6; border-left:5px solid #f0a500; padding:14px 16px;">总结来看，6月25日韩国股市的指数表现很强，但强势并不均匀。KOSPI主要由半导体龙头推动，KOSDAQ的下跌说明中小成长股仍然承压。下一步要观察的是，半导体行情能否扩散，还是继续停留在少数大型权重股中。</p>
