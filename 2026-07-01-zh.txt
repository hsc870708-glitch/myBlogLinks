  <h1 style="font-size:28px; color:#111; margin:0 0 16px;">KOSPI走弱、KOSDAQ反弹：2026年7月1日韩国股市收盘解读</h1>
  <p style="font-size:16px; margin:0 0 14px;">2026年7月1日，韩国股市在下半年首个交易日呈现明显分化。截至下午3点30分收盘，KOSPI收于8,303.06点，下跌173.42点，跌幅2.05%；KOSDAQ收于929.30点，上涨13.12点，涨幅1.43%。KOSPI市场中，外资净卖出约2万亿韩元，个人和机构分别净买入约1.23万亿韩元和7,407.3亿韩元。KOSDAQ则相反，外资净买入约2,236.4亿韩元，为指数反弹提供支撑。1)</p>
  <p style="font-size:16px; margin:0 0 18px;">今天的韩国股市不能简单理解为“整体转弱”。更准确地说，大盘权重股受到资金面压力，而部分中小盘、政策主题和成长主题重新获得关注。美国科技股上涨、韩国6月出口创纪录，本来都是利好消息；但在KOSPI权重股上，外资获利了结、程序化卖盘以及韩国国民年金重新进行国内股票再平衡的担忧，压过了这些利好。2)</p>

  <h2 style="font-size:22px; color:#111; margin:28px 0 10px;">为什么出口数据很好，KOSPI却下跌？</h2>
  <p>KOSPI早盘受到美国科技股上涨和韩国半导体出口强劲的带动，一度具备较好的开局条件。但随着交易推进，外资卖盘和程序化交易压力增强，指数转为下跌。对于不熟悉韩国市场的读者来说，这里有一个关键点：韩国股市高度依赖少数大型半导体和指数权重股，当这些股票前期涨幅过大时，即使宏观数据向好，也可能因为资金再平衡和获利回吐而出现调整。1)</p>
  <p>换句话说，今天市场并不是否定韩国经济和半导体周期，而是在重新评估价格。上半年韩国股市已经在AI、存储芯片和大型科技股带动下出现强劲上涨。到了下半年第一天，投资者开始关心的问题从“数据是否足够好”变成了“股价是否已经提前反映太多好消息”。</p>
  <h2 style="font-size:22px; color:#111; margin:28px 0 10px;">国民年金再平衡为何影响市场情绪？</h2>
  <p>当天最重要的心理变量之一，是韩国国民年金国内股票再平衡宽限期结束。Invest Chosun报道称，市场上午走弱时，外资和程序化卖压更为突出，而国民年金相关卖出更像是触发投资者获利了结的理由。需要注意的是，国民年金并不是一天内集中抛售全部股票；但市场往往会提前反映未来可能出现的持续性卖压。2)</p>
  <p>因此，真正值得观察的不是“会卖多少”这个单一数字，而是谁来吸收这些筹码。如果个人投资者和国内机构持续买入，冲击可能被分散；但如果外资卖出、程序化卖出和养老金再平衡在同一天同向发生，大型股的压力就会被放大。今天KOSPI的下跌，正是这种资金面担忧集中体现的一天。</p>
  <h2 style="font-size:22px; color:#111; margin:28px 0 10px;">6月出口创新高，为什么仍需冷静解读？</h2>
  <p>韩国6月出口数据非常强。根据引用产业通商资源部数据的报道，6月韩国出口额达到1,022.5亿美元，同比增长70.9%，首次突破单月1,000亿美元。半导体出口达到448.2亿美元，同比增长199.5%，也是首次突破单月400亿美元。3)</p>
  <p>从实体经济角度看，这是非常积极的信号，说明AI基础设施投资、存储芯片需求和价格周期仍在支撑韩国出口。但股市并不只看当下数据，还会判断未来增速是否还能继续超预期。由于韩国半导体龙头和相关大型股在上半年已经大幅上涨，今天的强劲出口数据反而成为投资者检验估值和兑现利润的窗口。</p>
  <h2 style="font-size:22px; color:#111; margin:28px 0 10px;">KOSDAQ为何逆势上涨？</h2>
  <p>KOSDAQ的走势与KOSPI不同。7月1日正好是KOSDAQ市场成立30周年，韩国交易所公布了恢复市场信任和推动制度改革的方向，包括强化劣质企业退市制度、推动优质企业分层的“ KOSDAQ Select ”构想，以及支持AI、生物科技、半导体、国防和航天等创新企业上市。4)</p>
  <p>这些制度安排不会立刻改变所有公司的业绩，但会改变投资者对市场的关注点。上半年资金高度集中在KOSPI大型半导体股，KOSDAQ相对被冷落。今天政策预期、外资买入和主题轮动同时出现，使得部分资金愿意重新审视中小盘成长股。不过，单日上涨还不足以说明趋势已经彻底反转，后续仍要看外资买入能否持续、成交额是否放大，以及上涨是否从少数主题扩散到更多优质公司。</p>
  <h2 style="font-size:22px; color:#111; margin:28px 0 10px;">行业和代表性主题：资金流向哪里？</h2>
  <p>AlphaSquare数据显示，当天涨幅靠前的主题包括水泥与混凝土、建筑土木、京釜高速公路地下化、电力设备和铜。行业平均收益率靠前的板块包括建筑与基础设施、旅游休闲、IT/ICT、运输和能源。1) 这说明今天市场并没有只盯着半导体出口，而是把视线转向基建、电网、政策项目和原材料相关方向。</p>
  <p>个股层面，东洋File、东信建设、HC宝光产业等建筑材料和建设相关股票涨停或接近涨停；外资净买入排名中，三星电机、EO Technics、Wonik IPS、DB HiTek、ISC等电子零部件和半导体设备链公司靠前。1) 这点尤其值得注意：外资卖出KOSPI整体，并不等于完全撤离韩国科技产业链。更像是从涨幅较大的指数权重股中减仓，同时在零部件、设备、材料等细分环节寻找机会。</p>
  <h2 style="font-size:22px; color:#111; margin:28px 0 10px;">下一交易日应关注什么？</h2>
  <ul style="padding-left:20px; margin:0 0 20px;">
    <li>外资是否继续净卖出KOSPI，特别是大型半导体股的卖压是否缓和。</li>
    <li>国民年金再平衡相关担忧是否在每日资金流中继续体现。</li>
    <li>个人和国内机构能否持续吸收大盘股卖盘。</li>
    <li>KOSDAQ反弹是否伴随外资持续买入和成交额增加。</li>
    <li>出口强劲能否扩散到设备、材料、零部件公司的业绩预期，而不仅停留在大型芯片公司。</li>
    <li>韩元兑美元汇率和美国科技股走势是否继续支持外资风险偏好。</li>
  </ul>
  <div style="background:#fff8e6; border:1px solid #f0d58a; padding:15px 18px; margin:24px 0;">
    <strong>收盘解读</strong>
    <p style="margin:8px 0 0;">7月1日的韩国股市显示，下半年行情可能不再是上半年那种单纯依靠大型半导体股推动的直线上涨，而会更依赖资金承接能力、板块轮动和个股选择。KOSPI下跌并不代表韩国基本面突然恶化，更像是前期强势权重股消化涨幅。KOSDAQ反弹带有积极信号，但是否形成持续趋势，还需要后续几个交易日继续验证。</p>
