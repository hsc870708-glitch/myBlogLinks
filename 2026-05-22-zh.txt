  <h1 style="font-size:30px; line-height:1.35; margin:0 0 18px; color:#111;">2026年5月22日韩国股市收盘解读：KOSPI放缓，KOSDAQ大涨，市场资金开始明显轮动</h1>
  <p style="margin:0 0 14px;">5月22日的韩国股市，如果只看表面，很容易觉得有些分裂。前一天暴涨之后，KOSPI在7,800点附近进入“喘口气”的节奏；而以成长股为主的KOSDAQ却明显走强，冲到1,150点一带，资金快速流向生物医药、二次电池、机器人等板块。用一句更容易理解的话来说，今天不是风险偏好消失了，而是市场把风险偏好的方向换了。2)3)</p>
  <p style="margin:0 0 18px; padding:14px 16px; background:#f5f7fb; border-left:5px solid #2f6fed;">本文依据5月22日收盘前后可核实的公开报道和市场资料撰写。由于生成时可访问的公开来源并没有全部同步展示完全一致的最终收盘数字，正文更侧重已经确认的指数区间、资金流向和板块表现，而不是勉强给出未经充分交叉验证的精确收盘点位。2)3)</p>

  <div style="background:#fff7ea; border:1px solid #f0d5a2; padding:16px 18px; margin:0 0 24px; border-radius:8px;">
    <strong style="display:block; font-size:18px; margin-bottom:10px; color:#8a5600;">先看重点</strong>
    <ul style="margin:0; padding-left:20px;">
      <li>KOSPI在前一天大涨8.42%之后，5月22日明显进入整理节奏。5月21日收于7,815.59点，22日开盘报7,873.12点，盘中一度回落到7,780点区间，说明市场仍然有不小的波动。2)9)</li>
      <li>KOSDAQ则持续强势，连续第二个交易日触发买入侧边车机制，外资和机构集中买入成长股，EcoPro BM、EcoPro、Alteogen等成为核心焦点。2)4)5)</li>
      <li>今天韩国股市最关键的信号，不是“市场变弱”，而是“资金换了去处”。半导体大市值股票休息，政策预期和低位补涨逻辑推动KOSDAQ接棒。3)5)</li>
    </ul>

  <h2 style="font-size:24px; margin:28px 0 12px; color:#163b73;">指数与整体市场节奏</h2>
  <p style="margin:0 0 14px;">如果要用最简单的话概括今天的韩国股市，那就是“KOSPI休息，KOSDAQ奔跑”。据韩联社报道，主板市场上外资在有价证券市场连续第12个交易日净卖出，而个人和机构资金在承接抛压。相反，在KOSDAQ市场，外资和机构同时净买入，指数涨幅进一步扩大。对不熟悉韩国市场的读者来说，这一点非常重要，因为它说明今天并不是全面避险的一天，而是资金在同一个市场内部做了风格切换。2)3)</p>
  <p style="margin:0 0 14px;">很多初级投资者看到“KOSPI偏弱、KOSDAQ大涨”会觉得矛盾，其实并不矛盾。前一天推动KOSPI暴涨的是三星电子、SK海力士这类超大市值半导体龙头，而今天它们集体放缓，市场自然需要新的领涨方向。于是，相对涨幅没那么夸张、又带有政策想象空间的成长股接过主导权。换句话说，今天韩国市场并不是没信心，而是在重新分配信心。2)3)5)</p>

  <h2 style="font-size:24px; margin:28px 0 12px; color:#163b73;">今天市场为什么这样走？</h2>
  <h3 style="font-size:20px; margin:18px 0 8px; color:#222;">1. 美伊谈判预期改善，油价回落，情绪得到支撑</h3>
  <p style="margin:0 0 14px;">隔夜美股三大指数小幅收高，道指再创历史新高。韩联社指出，市场情绪受到美国与伊朗谈判预期改善、国际油价回落的支撑。布伦特原油和WTI走低，有利于缓解输入型通胀和中东局势对韩国市场的压力。不过，特朗普在伊朗高浓缩铀问题上的强硬表态也意味着风险并没有彻底解除，这也是今天KOSPI没有延续前一天单边猛涨的重要原因。2)6)</p>
  <h3 style="font-size:20px; margin:18px 0 8px; color:#222;">2. 前一天涨得太猛，主板先消化涨幅很正常</h3>
  <p style="margin:0 0 14px;">5月21日，KOSPI单日上涨606.64点，收在7,815.59点；KOSDAQ也上涨49.90点，收在1,105.97点。经历如此剧烈的反弹之后，第二天马上继续同样速度上冲，本来就不现实。韩联社还提到，前一天外资在KOSPI200期货市场上的仓位变化，可能通过程序化交易影响了主板上方空间。用更通俗的语言来解释，就是昨天把指数拉上去的那股力量，今天有一部分进入了调仓和落袋阶段。2)9)</p>
  <h3 style="font-size:20px; margin:18px 0 8px; color:#222;">3. 韩国“国民成长基金”预期，把KOSDAQ点燃了</h3>
  <p style="margin:0 0 14px;">KOSDAQ今天的大涨，并不只是短线追涨。韩联社、Edaily和NoCut News都把焦点指向22日启动销售的国民参与型成长基金。市场普遍认为，这类资金未来有望支持生物医药、IT、机器人、航天等战略成长行业，因此投资者提前布局。资本市场经常会先交易“未来可能流入的钱”，再等待资金真正到位，今天的KOSDAQ就是这种典型案例。3)4)5)</p>

  <h2 style="font-size:24px; margin:28px 0 12px; color:#163b73;">板块与代表个股看点</h2>
  <p style="margin:0 0 14px;">大市值半导体今天明显降温。三星电子盘中一度触及30万韩元，但韩联社报道称，上午阶段一度呈现约2%的跌幅；SK海力士则在平盘附近来回波动。也就是说，前一天带动大盘暴涨的主角，今天主动休息了。因此，KOSPI看起来平静，并不代表整个韩国市场突然转弱。与此同时，LG新能源、三星电机、斗山能源等拥有各自逻辑的大盘股表现相对更稳，说明主板内部也不是全面熄火，而是热点在切换。2)</p>
  <p style="margin:0 0 14px;">KOSDAQ这边则更像“成长股接力赛”。EcoPro BM与EcoPro继续走强，Alteogen也加入反弹队伍。与此同时，HLB因参加ASCO 2026相关消息受到关注，进一步点燃了生物医药方向。对中国读者来说，这里最值得注意的不是某一只股票涨了多少，而是韩国市场在政策预期、外资回流和事件催化叠加时，成长板块的弹性会非常大。弹性大，意味着上涨很快，也意味着波动不会小。3)5)7)</p>

  <h2 style="font-size:24px; margin:28px 0 12px; color:#163b73;">下一交易日该看什么？</h2>
  <ul style="margin:0 0 16px; padding-left:22px;">
    <li>韩国股市下一个交易日是5月26日周二。5月25日周一因佛诞日补休，韩国交易所休市。1)8)</li>
    <li>KOSPI接下来最重要的，不只是半导体能不能反弹，更是外资连续净卖出的力度会不会缓和。如果外资继续撤出，主板即便守住7,800点附近，向上的速度也可能放慢。2)</li>
    <li>KOSDAQ经历连续两天侧边车之后，需要观察政策资金预期能否继续扩散到更广泛的中小成长股，还是很快转为短线获利回吐。3)4)5)</li>
    <li>生物医药板块在ASCO临近时仍可能维持热度，但学会行情往往在正式数据公布前后波动很大，不能只看情绪，不看内容。7)</li>
  </ul>

  <p style="margin:0 0 14px;">因此，5月22日的韩国股市真正想告诉投资者的，并不是“行情重新全面转强”，而是“市场重新有能力选择把风险押在哪里”。KOSPI没有崩，只是在历史级反弹后暂时休息；KOSDAQ则成为当天风险偏好重新释放的主要出口。对想理解韩国市场的人来说，今天最值得看的不是单一指数数字，而是资金在板块之间移动的速度和方向。2)3)5)</p>
  <p style="margin:18px 0 0; padding:14px 16px; background:#f3f5f7; border-radius:8px; color:#444;">这篇文章不是投资建议，而是一份帮助读者理解当天盘面变化的解释型市场报告。</p>
